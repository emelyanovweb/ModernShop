ModernShop

ModernShop - это полнофункциональный интернет-магазин с удобной панелью администратора. Проект разработан на чистом PHP с использованием MySQL и современного адаптивного дизайна.

Технологии

Backend: PHP 7.4+ (без фреймворков)
База данных: MySQL 5.7+
Frontend: HTML5, CSS3, JavaScript (Vanilla)
Стилизация: CSS переменные, Flexbox, Grid
Иконки: Font Awesome 6
Шрифты: Google Fonts (Inter)
Безопасность: Защита от SQL-инъекций, XSS

Использование

Доступ в админ-панель

Перейдите по адресу http://localhost/modernshop/admin.php
Используйте демо-доступ:

Логин: admin
Пароль: admin
Управление товарами

В админ-панели перейдите на вкладку "Товары"
Заполните форму добавления товара
Загрузите изображение (до 5MB, форматы: JPG, PNG, GIF, WEBP)
Нажмите "Добавить товар"
Управление категориями

Перейдите на вкладку "Категории"
Добавьте новую категорию
Изменяйте порядок сортировки с помощью поля "Порядок"
Включайте/отключайте категории с помощью переключателя
Создание промокодов

Перейдите на вкладку "Промокоды"
Введите код промокода (автоматически преобразуется в верхний регистр)
Выберите тип скидки (процентная или фиксированная)
Укажите значение скидки и срок действия
Нажмите "Добавить промокод"
Кастомизация внешнего вида

Перейдите на вкладку "Кастомизация"
Изменяйте цвета, шрифты и расположение элементов
Все изменения отображаются в реальном времени
Нажмите "Сохранить все" для применения изменений
CSS редактор

Перейдите на вкладку "CSS редактор"
Редактируйте CSS код с подсветкой синтаксиса
Изменения автоматически сохраняются через 2 секунды после остановки печати
